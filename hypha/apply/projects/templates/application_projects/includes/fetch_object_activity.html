{% comment %} A template that will handle the htmx request to retrieve the activity of an object via the provided URL. This template exists to provide a canned way to handle the open/closed status of the collapsible. If the collapsible is open, it shouldn't close on refresh. This is managed in `hx-vals`. Params: fetch_activity_url – the URL to pull the activities from (ie. `/apply/projects//project-sow//partial/status/`) extra_triggers - any other htmx triggers that should cause a refresh of the activities.
